# Getting help

Beehave is a volunteer-run open-source project. Here is where to go.

| You want to... | Go to |
| --- | --- |
| Learn how to use Beehave | The [documentation](https://guilyx.github.io/beehave/) |
| Ask a question, share a tree, discuss an idea | [GitHub Discussions](https://github.com/guilyx/beehave/discussions) |
| Report a graph that is wrong or confusing | [New issue: wrong graph](https://github.com/guilyx/beehave/issues/new?template=wrong_graph.yml) |
| Report a crash or another bug | [New issue: bug report](https://github.com/guilyx/beehave/issues/new?template=bug_report.yml) |
| Suggest a feature | [New issue: feature request](https://github.com/guilyx/beehave/issues/new?template=feature_request.yml) |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md) |
| Contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |

**Questions go to Discussions, bugs go to issues.** Issues are our to-do list;
keeping questions out of it means bugs get fixed faster. If a discussion turns
out to be a bug, we will convert it into an issue for you.

## Before you ask

- Check the [docs](https://guilyx.github.io/beehave/), in particular the
  [command line guide](https://guilyx.github.io/beehave/guide/cli/) and the
  list of [supported nodes](https://guilyx.github.io/beehave/design/phase-1/#node-support).
- Search [existing issues](https://github.com/guilyx/beehave/issues?q=is%3Aissue)
  and [discussions](https://github.com/guilyx/beehave/discussions).
- Run `beehave --version` and include the output.

## When you ask

Include the smallest tree that shows what you mean, the exact command you
ran, and what Beehave printed. Please only share trees you are allowed to
share publicly; rename nodes if you need to.

## Response times

There is no paid support and no guaranteed response time. We read everything
and answer as soon as we can, usually within a week. Answering other people's
questions in Discussions is one of the most helpful ways to contribute.
